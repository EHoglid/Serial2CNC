Serial2CNC

Send CNC files over TCP or Serial using a Windows desktop app or a Blazor UI backed by API and Agent services.

Built-in CNC/Device Support

  • USR-W610 serial-to-Wi-Fi/Ethernet converter workflow (TCP mode)
  • Okuma OSP7000L framing option for CNC transfer

Reference: USR-W610 product page

Windows setup (no Visual Studio required)

  1. Install the .NET 10 SDK on the computer used to publish; Visual Studio is not needed.
  2. Clone the repository and publish the Agent, API, and Web projects as self-contained win-x64 applications with dotnet publish.
  3. Install the published applications as automatic Windows services under a dedicated account with access to the CNC connection and program folder.
  4. Open http://127.0.0.1:62899, configure the working directory and TCP/Serial settings, then select a file and start the transfer.

The runtime computer does not need Visual Studio or the .NET runtime. See the README setup guide for the full PowerShell publish and Windows Service commands.

Network safety: the Agent and API listen on loopback by default. The application does not provide user authentication; do not expose it directly to an untrusted network.

Components

  • WPF Desktop: Serial2CNC
  • Blazor UI: Serial2CNC.Web
  • API Gateway: Serial2CNC.Api
  • Transfer Agent: Serial2CNC.Agent
