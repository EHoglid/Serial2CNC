Serial2CNC

Send CNC files over TCP or Serial using a Windows desktop app or a Blazor UI backed by API and Agent services.

Built-in CNC/Device Support

  • USR-W610 serial-to-Wi-Fi/Ethernet converter workflow (TCP mode)
  • Okuma OSP7000L framing option for CNC transfer

Reference: USR-W610 product page

Windows setup

  1. Download the Windows x64 MSI from GitHub Releases, once a version is released.
  2. Run the MSI and approve the administrator prompt. It installs the Agent, API, and Web as automatic Windows services, running even when nobody is logged on.
  3. Open http://127.0.0.1:62899, configure the working directory and TCP/Serial settings, then select a file and start the transfer.

For unreleased builds, download and unzip an installer artifact from a successful Windows MSI workflow run (GitHub sign-in required). Installers are currently unsigned; only install trusted builds.

See the README setup guide for checksum verification, building an MSI yourself, release instructions, and manual service-account installation.

Network safety: the MSI services use the highly privileged LocalSystem account and listen only on loopback. The application does not provide user authentication; keep it on a trusted computer and do not expose it directly to an untrusted network.

Components

  • WPF Desktop: Serial2CNC
  • Blazor UI: Serial2CNC.Web
  • API Gateway: Serial2CNC.Api
  • Transfer Agent: Serial2CNC.Agent
