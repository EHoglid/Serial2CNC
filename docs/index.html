Serial2CNC

Send CNC files over TCP or Serial using WPF, Blazor, API, and Agent services.

Built-in CNC/Device Support

  • USR-W610 serial-to-Wi-Fi/Ethernet converter workflow (TCP mode)
  • Okuma OSP7000L framing option for CNC transfer

Reference: USR-W610 product page

Setup on a Computer

  1. Install .NET 10 SDK and Visual Studio with .NET workloads.
  2. Clone https://github.com/EHoglid/Serial2CNC.git.
  3. Open Serial2CNC.slnx.
  4. Start Serial2CNC.Agent, Serial2CNC.Api, and Serial2CNC.Web.
  5. Configure working directory/filter in Settings and select files from File browser.

Components

  • WPF Desktop: Serial2CNC
  • Blazor UI: Serial2CNC.Web
  • API Gateway: Serial2CNC.Api
  • Transfer Agent: Serial2CNC.Agent
