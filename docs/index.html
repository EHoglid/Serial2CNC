Serial2CNC

Send CNC files using the Windows desktop application (TCP/IP or serial), or a single Docker application (TCP/IP only).

Built-in CNC/Device Support

  • USR-W610 serial-to-Wi-Fi/Ethernet converter workflow (TCP mode)
  • Okuma OSP7000L framing option for CNC transfer

Reference: USR-W610 product page

Windows setup

  1. Download the Windows x64 EXE installer from GitHub Releases, once a version is released.
  2. Run the installer and launch Serial2CNC from the Start menu. No Windows services or separate .NET runtime are required.
  3. Configure TCP/IP or serial settings and select a file. Desktop settings are preserved per user across restarts and upgrades.
  4. Optionally enable the built-in LAN web application in Settings and open http://localhost:62899. It supports TCP/IP and serial while the desktop app is running.

For unreleased builds, download an installer artifact from the Windows EXE workflow (GitHub sign-in required). Installers are currently unsigned; only install trusted builds.

See the README setup guide for checksum verification, Docker deployment, installer builds and migration from older MSI installations.

Network safety: the web application uses HTTP and has no user authentication. Use a trusted private LAN only; do not expose it directly to the internet.

Components

  • WPF Desktop: Serial2CNC
  • Single Docker server and embedded Blazor UI: Serial2CNC.Web
  • Shared transfer runtime library: Serial2CNC.Agent
